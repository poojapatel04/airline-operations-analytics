# ✈️ Airline Data Analysis Project

## 📊 Overview
This project analyzes airline flight performance and customer satisfaction data to identify trends in delays, operational efficiency, and passenger experience. The goal is to extract actionable insights that can support better decision-making in airline operations.

---

## 🛠 Tools & Technologies
- SQL (data cleaning & analysis)
- Python (data exploration & analysis)
- Pandas
- Excel (supporting analysis)
- Data visualization (optional if added)

---

## 📁 Dataset
The dataset includes:
- Flight performance data (delays, routes, timing)
- Customer satisfaction survey data
- Sample test dataset for validation

---

## 🔄 Data Cleaning (SQL)
- Removed null and duplicate records
- Standardized column formats
- Handled missing values
- Created structured datasets for analysis

---

## 📈 Key Analysis
- Flight delay patterns by time and route
- Average delay comparisons
- Customer satisfaction trends
- Operational inefficiencies in flight schedules

---

## 📌 Key Insights
- Certain routes show consistently higher delays
- Customer satisfaction is strongly impacted by arrival delays
- Peak hours contribute significantly to operational inefficiency

---

## 🎯 Outcome
This project demonstrates how raw airline operational data can be transformed into meaningful insights that support decision-making in transportation and operations analytics.
